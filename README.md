# Selwyn Mallah
### Finance Transformation · AI-Enabled FP&A & Financial Systems

I work at the intersection of financial planning & analysis, treasury, and
AI-assisted software development. My focus is turning manual, spreadsheet-bound
finance workflows into reliable, **auditable** systems that teams can trust and
use every week.

## What I'm building

- **AI-Powered 13-Week Cash Flow Forecast** — 🚧 *In development.*
  A synthetic-data application that produces a direct-method 13-week cash
  forecast. A **deterministic calculation engine** computes every number;
  an AI layer interprets the validated results, drafts variance commentary,
  flags anomalies, and answers questions — but never performs or invents
  calculations. Includes scenario analysis and automated accuracy tests.
  *(Repository goes public at launch.)*
- **FP&A Variance Analyst** — *Planned.*
- **Finance Operating System demo** — *Planned.*

## How I approach the work

Discover the workflow → define the financial model → prototype → validate with
tests & controls → deploy → measure adoption and value.
